# 수익화 가이드 — 애드센스와 검색 유입

이 사이트의 수익 구조는 단순합니다.

```
월 광고 수익 ≈ 월 페이지뷰 ÷ 1,000 × RPM(페이지뷰 1,000회당 수익)
월 비용      ≈ 0원 (+ 도메인 연 1~2만 원)
```

RPM 은 방문자 국가, 주제, 광고 배치에 따라 크게 달라지므로 실제 값은 애드센스 보고서로 확인하세요.
서버 비용이 트래픽에 비례해 늘지 않기 때문에, **페이지뷰를 늘리는 것 = 순수익 증가**입니다.

---

## 1. 애드센스 신청 전 체크리스트

- [ ] **커스텀 도메인 연결** — 애드센스에는 본인 소유 도메인만 등록할 수 있습니다 ([DEPLOY.md](DEPLOY.md#도메인-연결-애드센스-신청-전-필수)).
- [ ] 환경 변수 `PUBLIC_SITE_URL`, `PUBLIC_CONTACT_EMAIL` 설정 — 연락처가 있으면 사이트 신뢰도에 도움이 됩니다.
- [ ] **개인정보처리방침·이용약관·소개 페이지** 확인 — 이미 포함되어 있습니다 (`/privacy/`, `/terms/`, `/about/`).
  운영자 정보와 시행일(`src/views/InfoView.astro` 의 `EFFECTIVE_DATE`)을 실제에 맞게 검토하세요.
- [ ] **콘텐츠** — 각 도구 페이지에 사용 방법과 FAQ 가 들어 있습니다. 승인 가능성을 높이려면 가이드 글(아래 4번)을 몇 개 추가하세요.
- [ ] **검색엔진 등록** — Google Search Console 에 사이트맵을 제출해 페이지가 색인된 뒤 신청하면 심사가 원활합니다 (아래 3번).

## 2. 애드센스 설정 순서

1. [Google AdSense](https://adsense.google.com) 에 가입하고 **사이트 → 사이트 추가** 에서 도메인을 입력합니다.
2. 게시자 ID(`ca-pub-1234567890123456`)를 Cloudflare Pages 환경 변수 **`PUBLIC_ADSENSE_CLIENT`** 에 넣고 다시 배포합니다.
   - 모든 페이지 `<head>` 에 애드센스 스크립트가 들어가고,
   - `https://도메인/ads.txt` 가 자동으로 만들어집니다 (`google.com, pub-…, DIRECT, f08c47fec0942fa0`).
3. 애드센스의 사이트 연결 화면에서 **"AdSense 코드 스니펫"** 방식을 고르고 확인 → **검토 요청**을 누릅니다.
   심사는 보통 며칠에서 몇 주가 걸립니다.
4. 승인 후 광고를 켭니다. 두 가지 방법이 있고 함께 써도 됩니다.
   - **자동 광고**: 애드센스 → 광고 → 사이트별 "자동 광고" 켜기. 코드는 이미 들어가 있으므로 추가 작업이 없습니다.
   - **광고 단위(권장)**: 애드센스 → 광고 → 광고 단위 기준 → **디스플레이 광고**를 3개 만들고,
     각 코드의 `data-ad-slot` 값을 아래 환경 변수에 넣은 뒤 다시 배포합니다.

     | 환경 변수 | 위치 | 특징 |
     | --- | --- | --- |
     | `PUBLIC_ADSENSE_SLOT_RESULT` | 작업 완료(다운로드) 화면 | 사용자가 결과를 기다렸다 확인하는 화면이라 주목도가 가장 높음 |
     | `PUBLIC_ADSENSE_SLOT_TOOL` | 도구 바로 아래 | 모든 도구 페이지에 노출 |
     | `PUBLIC_ADSENSE_SLOT_CONTENT` | 사용 방법과 FAQ 사이, 홈 화면 | 검색으로 들어와 내용을 읽는 방문자에게 노출 |

   개발 서버(`npm run dev`)에서는 광고 자리가 점선 상자로 표시되어 위치를 미리 확인할 수 있습니다.
5. **유럽(EEA·영국·스위스) 방문자 동의 메시지**: 애드센스 → **개인정보 보호 및 메시지** → 유럽 규정 메시지를 만드세요.
   Google 인증 동의 관리 도구(CMP)가 자동으로 표시되며 코드 수정은 필요 없습니다. 설정하지 않으면 해당 지역의 광고 수익이 제한됩니다.

### 광고 정책 주의 (계정 정지 예방)

- 광고를 **다운로드·파일 선택 버튼 바로 옆에 두지 마세요.** 실수로 누르게 만드는 배치는 정책 위반입니다. 현재 배치는 버튼과 간격을 두었습니다.
- 광고 표시는 "광고"/"Advertisement" 로만 표기합니다 (이미 적용). "클릭해 주세요" 같은 유도 문구는 금지입니다.
- 본인 광고를 클릭하거나 지인에게 클릭을 부탁하면 안 됩니다.

## 3. 검색 유입 만들기 (SEO)

이미 적용된 것: 13개 언어의 도구별 전용 페이지, 검색 키워드를 담은 제목·설명, hreflang(+ 영어 `x-default`), canonical, 언어별 사이트맵, 구조화 데이터(FAQ·앱·빵 부스러기),
빠른 로딩(정적 HTML, 무거운 라이브러리 지연 로딩), 모바일 대응.

등록할 곳:

| 검색엔진 | 방법 |
| --- | --- |
| [Google Search Console](https://search.google.com/search-console) | 속성 추가 → 메타 태그 인증(`PUBLIC_GOOGLE_SITE_VERIFICATION`) 또는 DNS 인증(Cloudflare 자동) → **Sitemaps** 에 `sitemap-index.xml` 제출 |
| [네이버 서치어드바이저](https://searchadvisor.naver.com) | 사이트 등록 → HTML 태그 인증(`PUBLIC_NAVER_SITE_VERIFICATION`) → **요청 → 사이트맵 제출**에 `sitemap-0.xml` 제출 |
| [Bing Webmaster Tools](https://www.bing.com/webmasters) | Search Console 에서 가져오기 또는 `PUBLIC_BING_SITE_VERIFICATION` |

인증 값만 환경 변수에 넣고 다시 배포하면 메타 태그가 자동으로 들어갑니다.

## 4. 페이지뷰를 늘리는 방법

- **가이드 글 추가**: "PDF 용량 줄이는 법", "아이폰에서 PDF 합치기", "스캔한 PDF 회전하기" 같은 글은 롱테일 검색 유입을 만들고,
  각 글에서 해당 도구로 연결되어 광고 노출이 늘어납니다. Astro 의 Markdown 콘텐츠 기능으로 쉽게 추가할 수 있습니다.
- **이어서 작업하기**(구현됨): 결과 파일을 다른 도구로 바로 넘겨 "합치기 → 압축 → 암호 설정"처럼 한 방문에서 여러 페이지를 보게 합니다.
- **언어 추가**: 13개 언어가 이미 들어 있습니다. 러시아어·아랍어처럼 다른 언어도 사전 파일을 추가하면 해당 언어의 검색 결과에 노출됩니다 (README 의 "언어 추가하기").
- **도구 추가**: "PDF 서명·텍스트 추가"처럼 검색량이 많은 기능을 추가하면 새로운 유입 경로가 됩니다.

## 5. 추가 수익원 (선택)

- **후원 링크**: `PUBLIC_DONATION_URL` 에 Buy Me a Coffee·투네이션 등의 링크를 넣으면 푸터에 "후원하기" 버튼이 나타납니다.
- **유료 기능(향후)**: 서버 없이 운영하는 구조를 유지하면서도, 라이선스 키 검증처럼 가벼운 기능은
  Cloudflare Workers 무료 플랜(하루 10만 요청)으로 처리할 수 있습니다. 결제는 Lemon Squeezy·Paddle·토스페이먼츠 등을 연동하면 됩니다.

## 6. 성과 측정

- **Cloudflare Web Analytics** (무료, 쿠키 없음): Pages 프로젝트 설정에서 켜거나 `PUBLIC_CF_ANALYTICS_TOKEN` 에 토큰 입력.
- **Google Analytics 4**: `PUBLIC_GA_ID` 에 측정 ID 입력. (쿠키를 사용하므로 개인정보처리방침에 이미 안내되어 있습니다.)
- 애드센스 보고서에서 **페이지별 RPM** 을 확인해 광고 단위 위치를 조정하세요.
